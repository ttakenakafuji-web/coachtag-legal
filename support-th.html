แอป Mac, iPad และ Windows สำหรับติดแท็กวิดีโอการแข่งขันฟุตบอลและวาดแท็กติก

ติดต่อ

แจ้งข้อบกพร่อง สอบถาม หรือขอฟีเจอร์ได้ทางอีเมล: t.takenaka.fuji@gmail.com

หากพบข้อบกพร่อง การแจ้งอุปกรณ์ (Mac / iPad) เวอร์ชันของระบบปฏิบัติการ และสิ่งที่กำลังทำอยู่ จะช่วยให้เราแก้ไขได้เร็วขึ้น

คำถามที่พบบ่อย

  • ควรเลือกแผนไหน?
    เลือกเบสิกหากต้องการเพียงการติดแท็ก เพลย์ลิสต์ และการส่งออก หรือเลือกโปรหากต้องการเอฟเฟกต์ เช่น การวาดแท็กติกและการติดตามอัตโนมัติด้วย ทั้งสองแผนใช้ได้บน Mac และ iPad และเดือนแรกฟรี
  • สมัครสมาชิกไว้บนอุปกรณ์อื่น
    ลงชื่อเข้าด้วย Apple ID เดียวกัน แล้วแตะ "กู้คืนการซื้อ" ในหน้าการสมัครสมาชิกของแอป
  • ยกเลิกการสมัครสมาชิกอย่างไร?
    บน iPad ไปที่ การตั้งค่า > Apple ID > การสมัครสมาชิก บน Mac ไปที่ การตั้งค่าระบบ > Apple ID > สื่อและการซื้อ > การสมัครสมาชิก ยกเลิกได้ทุกเมื่อ
  • ใช้งานบน Windows
    ดาวน์โหลด CoachTag สำหรับ Windows ได้จาก Microsoft Store และสมัครสมาชิกในแอปผ่าน Microsoft Store การสมัครสมาชิกผูกกับบัญชี Microsoft ของคุณ จึงใช้บนพีซีเครื่องอื่นได้เมื่อลงชื่อเข้าใช้ด้วยบัญชีเดียวกัน การสมัครสมาชิกที่ซื้อบน Mac หรือ iPad (App Store) ไม่สามารถใช้บน Windows ได้ และในทางกลับกันก็เช่นกัน ยกเลิกได้ที่ account.microsoft.com/services
  • ย้ายข้อมูลระหว่าง Mac และ iPad อย่างไร?
    แชร์แพ็กเกจ (.ccpkg) ผ่าน iCloud Drive แอปไฟล์ หรือ AirDrop แล้วเปิดบนอุปกรณ์ใดก็ได้
  • เปลี่ยนภาษาอย่างไร?
    บน Mac เลือกเมนู CoachTag > การตั้งค่า… (⌘,) บน iPad แตะ "⚙️ การตั้งค่า" ที่แถบด้านบน แล้วเลือกภาษา (日本語, English, 한국어, Português, 简体中文, ไทย, Español, العربية)
  • การติดตามอัตโนมัติคลาดเคลื่อน
    ลากดิสก์ไปยังตำแหน่งที่ถูกต้องในเฟรมนั้น แล้วกด "ติดตามใหม่รอบจุดนี้" จุดที่แก้ไขจะแสดงเป็น ◆ บนไทม์ไลน์ และจะติดตามใหม่เฉพาะช่วงรอบๆ จุดนั้น
