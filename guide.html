1. まず、CoachTag の考え方

CoachTag は、映像を「切る」のではなく、「印を付ける」ことで場面を集めるアプリです。ここが一般的な動画編集ソフトとのいちばん大きな違いです。

動画編集ソフトとの違い

✂️ 一般的な動画編集ソフト
  1. 試合を最後まで見る
  2. 見返して、使う場面を探す
  3. 1つずつ切り出して書き出す
  4. 場面を変えたくなったら、また切り直す
見る作業と切る作業が別々。準備に試合の何倍もの時間がかかります。
🏷️ CoachTag
  1. 試合を見ながら、場面ごとにキーを押す
  2. 試合が終わった時点で、場面の一覧ができている
  3. 種類や条件で絞り込んで、集めるだけ
  4. 場面の長さを変えるのも、印を直すだけ
見る作業と集める作業が同時に終わります。

「タグ」は、映像に貼るふせん

本にふせんを貼るのと同じです。ページ(映像)はそのままで、ふせん(タグ)だけが増えていきます。ふせんの色で「攻撃・良い」「守備・悪い」などの種類を分けておけば、あとで同じ色のふせんのページだけを開けます。

たとえば「クロスからのシュートを全部見せたい」とき

✂️ 動画編集ソフトだと
  1. 90分の映像を見返して、クロスからのシュートを探す
  2. 見つけるたびに、始まりと終わりを決めて切る
  3. 切ったものを並べて書き出す
  4. 次の試合でも、また最初から
🏷️ CoachTag だと
  1. (試合を見ながら打ったタグがすでにある)
  2. 表で「AT Good × クロス」をクリック → 該当場面がすべて選ばれる
  3. プレイリストへ追加して書き出す
  4. 何試合分でも、同じ操作でまとめられる

CoachTag のよいところ

⏱️見終わったら、もう集まっている試合を見ながらタグを打つので、見返して探す時間がいりません。試合中やハーフタイムにも使えます。
🔎条件でまとめて取り出せる「守備・悪い」だけ、「セットプレー × CK」だけ、のように種類とフラグで一瞬で絞り込めます。
💾ファイルも容量も増えないタグはただの印なので、何百個打っても映像1本分のまま。切ったファイルの管理に悩みません。
↩️何度でもやり直せる場面を長くしたい・短くしたいときは印を直すだけ。元の映像はいつでも無傷です。
📚試合をまたいで集められる複数の試合のタグを1つのプレイリストに。「今季の失点シーン」もすぐに作れます。
✏️描き込みも、そのまま書き出し場面に矢印やゾーンを描き込み、焼き込んだ動画として選手に渡せます。

全体の流れ

1📂開く試合の映像をパッケージに 2🏷️打つ見ながらタグを打つ 3📋集めるプレイリストにまとめる 4✏️描く戦術を描き込む 5🎬書き出す選手に見せる動画に

2. 覚えておきたい5つの言葉

📦 パッケージ
.ccpkg		試合の映像と、そこに打ったタグ・描画をひとまとめにした保存ファイルです。1試合につき1つ作ります。Mac・iPad・Windows のどれでもそのまま開けます。
🏷️ タグ「この場面」という時間の印です。AT Good(攻撃・良い)のようなボタンを押すと、その種類のタグが1つ打たれます。どのボタンを用意するかは自由に決められます。
📌 フラグタグに付け足す補足情報です。例えば「AT Good」のタグに「シュート」「クロス」などを付けておくと、あとで「シュートで終わった良い攻撃」だけを集められます。
📋 プレイリスト選んだタグを、見せたい順に並べたリストです。複数の試合(パッケージ)のタグを1つにまとめられます。映像はコピーせず、元のパッケージを参照します。
✏️ エフェクトモード1つの場面に入り込んで、矢印・ゾーン・選手を追いかけるマーカーなどを描き込むモードです。描いたものは書き出すときに映像へ焼き込まれます。

3. 試合の映像を開く(パッケージを作る)

  1. 動画を開くを押し、試合の動画ファイルを選びます。
  2. パッケージの名前と保存先を聞かれるので、決めます(例: 「第10節 vs ○○」)。
  3. 動画をパッケージの中へコピーするか移動するかを選びます(Mac・Windows)。元の場所にも動画を残したいときは「コピーする」を選んでください。
前半・後半などで動画が複数のファイルに分かれている場合は、まとめて選ぶとファイル名の順につないで開きます。
2回目からはパッケージを開くで、タグや描画ごと続きから作業できます。

4. タグのボタンを用意する

映像の下に並ぶボタンが、タグを打つためのボタンです。チームの分析の観点に合わせて作り直すのがおすすめです。

  1. ⚙️ タグ設定を開きます。
  2. 「タグ」タブで、ボタンの名前・色・キーボードショートカット(1文字)を決めます。+ タグを追加で増やせます。
  3. 必要なら「フラグ」タブで、補足情報のボタン(シュート・クロスなど)も作ります。

タグの打ち方は2種類

👆 ワンクリック

押した瞬間の前後数秒が自動でタグになります。何秒前から・何秒後までは設定できます。「シュートの瞬間」のように、決まった一点がある場面向き。

✌️ 始点→終点クリック

1回目で始まり、2回目(同じボタン)で終わりが決まります。「攻撃が始まってからボールを失うまで」のように、長さがまちまちな場面向き。

打ち方は⚙️ タグ設定で、全体の既定とタグごとの個別設定の両方を選べます。

よく使うボタン構成は「プリセット」として保存しておくと、次の試合でも同じボタンを呼び出せます。

5. 見ながらタグを打つ

映像を再生し、場面が来たらボタン(または割り当てたキー)を押すだけです。

  • Space で再生/一時停止、← → で3秒戻る/進む、J K L で巻き戻し/停止/早送りです。
  • 打ち間違えたら、一覧で選んで削除するか、⌘+Z(Windows は Ctrl+Z)で取り消せます。
  • タグを選んだ状態でフラグのボタンを押すと、そのタグにフラグが付きます(もう一度押すと外れます)。
  • 画面を大きく見たいときは⛶ 全画面表示にすると、よく使うボタンだけが映像の上に浮かんで表示されます。
最初は完璧を目指さず、「とりあえず多めに打って、あとで選ぶ」くらいがおすすめです。タグはただの印なので、増えても困りません。

6. 打ったタグを見返す・絞り込む

📊 テーブルを開くと、タグ×フラグの件数が表で見られます。数字をクリックすると、その条件に合うタグがまとめて選択されます。

  • 一覧のタグをクリックすると、その場面だけが再生されます。
  • 一覧の上の並び替え(タイムライン順・タグ順・ラベル順)で、同じ種類のタグをまとめて見られます。

7. プレイリストにまとめる

選手に見せたい場面を集めて並べるのがプレイリストです。プレイリストを開くと、映像の下にタグボードが出ます。

  1. 新規プレイリストで、プレイリストを作ります。
  2. タグ一覧の ➕(または選択したタグのプレイリストへ追加)で、場面を追加します。別の試合のパッケージを開いて、同じプレイリストに追加することもできます。
  3. タグボードで帯をドラッグして並べ替えたり、別の行へ移したりします。行は➕ 行を追加で増やせます。
  4. 行の ▶ で、その行だけを順に連続再生できます。スライドを挿入で、場面の間に説明用のページを挟むこともできます。
プレイリストは元のパッケージを参照しています。パッケージを移動・削除すると、その場面が再生できなくなるのでご注意ください。人に渡すときは📦 スタンドアロン化で、パッケージがなくても開ける形にできます。

8. 戦術を描き込む(プロプラン)

エフェクトモードはプロプランの機能です。
  1. タグ一覧(またはプレイリストの場面)の ✏️ を押すと、その場面のエフェクトモードに入ります。
  2. 左のツールから、ディスク・スポット・矢印・ゾーンなどを選んで映像の上に描きます。ディスクやスポットは、選手をクリックするだけで自動で追いかけます。
  3. 下のタイムラインで、描いたものを出す時間を調整します。説明したい瞬間で映像を止める「静止画」も入れられます。
  4. 描いたものは自動で保存されます。エフェクトモードを終了で元の画面に戻ります。

9. 動画として書き出す

  • 1つの場面だけ: タグの🎬 このクリップを書き出す。
  • プレイリスト全体を1本に: 🎬 動画として書き出す。タグボードで行にチェックを入れておくと、その行だけが対象になります。
  • 場面ごとに別々のファイルで: 🗂 クリップごとに個別に書き出す。

10. 切り取り済みのクリップから始める

すでに場面ごとに切り出した動画ファイルを持っている場合は、タグを打つ手順を飛ばせます。

  1. 動画からプレイリストを作成を押し、動画ファイルをまとめて選びます。
  2. 1ファイルが1つの場面になり、プレイリストができあがります。
  3. あとは7〜9と同じように、並べ替え・描き込み・書き出しができます。
