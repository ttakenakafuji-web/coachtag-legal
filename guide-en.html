CoachTag User Guide

1. First, how CoachTag works

CoachTag collects moments by “marking” the video, not by “cutting” it. That is the biggest difference from ordinary video editors.

How it differs from a video editor

✂️ Typical video editor
  1. Watch the whole match
  2. Go back and find the moments you need
  3. Cut and export them one by one
  4. To change a moment, cut it again
Watching and cutting are separate jobs, so preparation takes many times the length of the match.
🏷️ CoachTag
  1. Press a key for each moment as you watch
  2. When the match ends, your list of moments is ready
  3. Filter by type or condition, and collect
  4. To change a moment's length, just adjust the mark
Watching and collecting finish at the same time.

A “tag” is a sticky note on the video

It works like sticky notes in a book. The pages (video) stay as they are; only the notes (tags) are added. If you use note colors for types such as “attack, good” or “defense, bad,” you can later open only the pages with a given color.

Example: you want to show every shot that came from a cross

✂️ With a video editor
  1. Rewatch 90 minutes to find shots from crosses
  2. Each time, set a start and end, then cut
  3. Line up the cuts and export
  4. Start over for the next match
🏷️ With CoachTag
  1. (The tags you added while watching are already there)
  2. In the table, click “AT Good × Cross” → every matching moment is selected
  3. Add them to a playlist and export
  4. Collect from any number of matches the same way

What CoachTag does well

⏱️Done watching, already collectedYou tag as you watch, so there is no time spent rewatching and searching. It works during a match or at half-time too.
🔎Pull moments out by conditionFilter instantly by type and flag, such as only “defense, bad” or only “set piece × CK.”
💾No extra files or storageTags are only marks, so hundreds of them still leave you with one video. There are no cut files to manage.
↩️Redo as often as you likeTo lengthen or shorten a moment, just adjust the mark. The original video always stays intact.
📚Collect across matchesPut tags from several matches in one playlist. A “goals conceded this season” reel takes no time.
✏️Drawings export with the videoDraw arrows and zones on a moment and give players a video with them burned in.

2. Five terms to know

📦 Package
.ccpkg		A saved file that holds the match video with its tags and drawings. Make one per match. It opens as is on Mac, iPad and Windows.
🏷️ TagA time mark meaning “this moment.” Pressing a button such as AT Good (attack, good) adds one tag of that type. You decide which buttons to have.
📌 FlagExtra information added to a tag. For example, add “Shot” or “Cross” to an “AT Good” tag, and you can later collect only “good attacks that ended in a shot.”
📋 PlaylistA list of selected tags in the order you want to show them. It can combine tags from several matches (packages). No video is copied; it refers to the original packages.
✏️ Effects modeA mode for working inside one moment, drawing arrows, zones, markers that follow players and more. Your drawings are burned into the video on export.

3. Open match video (create a package)

  1. Press Open Video and choose the match video file.
  2. When asked, set the package name and save location (for example “Matchday 10 vs XX”).
  3. Choose whether to copy or move the video into the package (Mac, Windows). To keep the video in its original location too, choose “Copy.”
If the video is split into several files, such as first and second half, select them together and they open joined in file name order.
Next time, use Open Package to carry on with your tags and drawings.

4. Set up tag buttons

The buttons below the video are the ones you tag with. We recommend rebuilding them to match your team's analysis points.

  1. Open ⚙️ Tag Settings.
  2. In the “Tags” tab, set each button's name, color and keyboard shortcut (1 character). Use + Add Tag to add more.
  3. If needed, create extra-information buttons (Shot, Cross and so on) in the “Flags” tab.

Two ways to tag

👆 One click

The few seconds around the moment you press automatically become a tag. You can set how many seconds before and after. Best for moments with one clear point, such as “the instant of a shot.”

✌️ Start → End click

The first press sets the start, and the second press of the same button sets the end. Best for moments of varying length, such as “from the start of an attack until we lose the ball.”

In ⚙️ Tag Settings you can choose both the overall default and a method for each tag.

Save a button layout you use often as a “preset,” and you can load the same buttons for the next match.

5. Tag while you watch

Play the video, and when a moment comes, just press the button (or its key).

  • Space plays and pauses, ← → go back and forward 3 seconds, and J K L rewind, stop and fast-forward.
  • If you make a mistake, select the tag in the list and delete it, or undo with ⌘+Z (Ctrl+Z on Windows).
  • With a tag selected, press a flag button to add that flag to it (press again to remove it).
  • To see the picture larger, switch to ⛶ Full Screen. Only your most-used buttons float over the video.
Don't aim for perfection at first. It's better to tag generously and choose later. Tags are only marks, so having extra does no harm.

6. Review and filter your tags

Open 📊 Table to see tag × flag counts. Click a number to select all the tags that match it.

  • Click a tag in the list to play just that moment.
  • Use the sort options above the list (Timeline order, By tag, By label) to view tags of the same type together.

7. Build a playlist

A playlist gathers the moments you want to show your players and puts them in order. When you open a playlist, the Tag Board appears below the video.

  1. Create a playlist with New Playlist.
  2. Add moments with ➕ in the tag list (or Add to Playlist for selected tags). You can also open another match's package and add to the same playlist.
  3. Drag bands on the Tag Board to reorder them or move them to another row. Add rows with ➕ Add Row.
  4. Press ▶ on a row to play just that row in sequence. Use Insert Slide to put an explanation page between moments.
A playlist refers to the original packages, so moving or deleting a package stops its moments from playing. When giving a playlist to someone else, use 📦 Make Standalone so it opens without the packages.

8. Draw tactics (Pro plan)

Effects mode is a Pro plan feature.
  1. Press ✏️ in the tag list (or on a playlist moment) to enter Effects mode for that moment.
  2. Choose a tool on the left, such as Disc, Spotlight, Arrow or Zone, and draw over the video. Disc and Spotlight follow a player automatically with a single click.
  3. Use the timeline below to adjust when each drawing appears. You can also add a “Freeze” to stop the video at the moment you want to explain.
  4. Your drawings are saved automatically. Press Exit Effects Mode to return to the previous screen.

9. Export as video

  • One moment only: 🎬 Export this clip on the tag
  • The whole playlist as one video: 🎬 Export as Video Check rows on the Tag Board to export only those rows.
  • A separate file per moment: 🗂 Export Clips Separately

10. Start from ready-made clips

If you already have video files cut by moment, you can skip the tagging steps.

  1. Press New Playlist from Videos and select your video files together.
  2. Each file becomes one moment, and the playlist is ready.
  3. From there you can reorder, draw and export as in sections 7–9.
