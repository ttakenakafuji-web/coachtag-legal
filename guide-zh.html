1. 首先了解 CoachTag 的思路

CoachTag 不是通过“剪切”视频，而是通过“做记号”来收集场景。这是它与普通视频剪辑软件最大的不同。

与视频剪辑软件的区别

✂️ 普通视频剪辑软件
  1. 把比赛看完
  2. 回看并寻找要用的场景
  3. 一个一个剪出来并导出
  4. 想换场景时，还要重新剪
看和剪是分开的两项工作，准备时间往往是比赛时长的好几倍。
🏷️ CoachTag
  1. 边看比赛，边在每个场景按键
  2. 比赛看完时，场景列表已经完成
  3. 按类型或条件筛选后收集即可
  4. 改变场景长度，也只需修改记号
看和收集同时完成。

“标签”就是贴在视频上的便利贴

就像在书上贴便利贴。页面（视频）保持不变，只有便利贴（标签）不断增加。用便利贴的颜色区分“进攻·好”“防守·差”等类型，之后就能只翻开同一颜色的页面。

例如：想展示所有“传中后的射门”时

✂️ 用视频剪辑软件
  1. 回看90分钟视频，寻找传中后的射门
  2. 每找到一次，就确定起止点并剪切
  3. 把剪好的片段排好并导出
  4. 下一场比赛又要从头开始
🏷️ 用 CoachTag
  1. （看比赛时打的标签已经有了）
  2. 在表格中点击“AT Good × 传中” → 相关场景全部选中
  3. 添加到播放列表并导出
  4. 无论多少场比赛，都能用同样的操作整理

CoachTag 的优点

⏱️看完时，场景已收集好边看比赛边打标签，不用花时间回看寻找。比赛中和中场休息时也能使用。
🔎按条件一次取出只看“防守·差”、只看“定位球 × CK”，用类型和标记瞬间筛选。
💾文件和空间都不增加标签只是记号，打几百个也还是一个视频，不用为管理剪好的文件发愁。
↩️可以反复修改想让场景变长或变短，只需修改记号。原视频始终完好无损。
📚可以跨比赛收集把多场比赛的标签放进一个播放列表。“本赛季失球集锦”也能马上做好。
✏️绘制内容直接导出在场景上画箭头和区域，做成已合成的视频交给球员。

整体流程

1📂打开把比赛视频放入资料包 2🏷️打标签边看边打标签 3📋收集整理成播放列表 4✏️绘制画上战术 5🎬导出做成给球员看的视频

2. 需要记住的5个词

📦 资料包
.ccpkg		把比赛视频和其中的标签、绘制内容合在一起的保存文件。每场比赛做一个。在 Mac、iPad、Windows 上都能直接打开。
🏷️ 标签表示“这个场景”的时间记号。按下 AT Good（进攻·好）这样的按钮,就会打上一个该类型的标签。准备哪些按钮可以自由决定。
📌 标记附加在标签上的补充信息。例如给“AT Good”标签加上“射门”“传中”等，之后就能只收集“以射门结束的好进攻”。
📋 播放列表把选中的标签按想展示的顺序排列的列表。可以把多场比赛（资料包）的标签合在一起。不复制视频，而是引用原资料包。
✏️ 效果模式进入一个场景，绘制箭头、区域、跟随球员的标记等的模式。绘制内容在导出时合成到视频中。

3. 打开比赛视频（创建资料包）

  1. 按下 打开视频,选择比赛视频文件。
  2. 根据提示设定资料包名称和保存位置（例如“第10轮 vs ○○”）。
  3. 选择把视频复制还是移动到资料包中（Mac、Windows）。如果想在原位置也保留视频，请选择“复制”。
如果视频分成上半场、下半场等多个文件，一起选中后会按文件名顺序连接打开。
从第二次起，用 打开资料包 就能连同标签和绘制内容继续工作。

4. 准备标签按钮

视频下方排列的按钮就是打标签用的按钮。建议根据球队的分析角度重新设置。

  1. 打开 ⚙️ 标签设置。
  2. 在“标签”选项卡中设定按钮的名称、颜色和键盘快捷键（1个字符）。用 + 添加标签 可以增加按钮。
  3. 需要时，在“标记”选项卡中也创建补充信息按钮（射门、传中等）。

打标签的方式有2种

👆 单击

按下瞬间的前后几秒自动成为标签。前后各几秒可以设置。适合“射门瞬间”这样有明确时间点的场景。

✌️ 起点 → 终点点击

第一次按下确定开始，第二次（同一按钮）确定结束。适合“从发起进攻到丢球”这样长度不一的场景。

打标签的方式可以在 ⚙️ 标签设置 中选择，既可设全局默认，也可为每个标签单独设置。

把常用的按钮配置保存为“预设”，下一场比赛也能调出同样的按钮。

5. 边看边打标签

播放视频，场景出现时按下按钮（或分配的按键）即可。

  • Space 播放/暂停，← → 后退/前进3秒，J K L 倒退/停止/快进。
  • 打错时，可在列表中选中后删除，或用 ⌘+Z（Windows 为 Ctrl+Z）撤销。
  • 选中标签时按下标记按钮，该标签就会加上标记（再按一次取消）。
  • 想看大画面时，切换到 ⛶ 全屏,常用按钮会浮动显示在视频上方。
一开始不必追求完美，建议“先多打一些，之后再挑选”。标签只是记号，多了也没关系。

6. 回看和筛选标签

打开 📊 表格,可以查看标签×标记的数量。点击数字，符合该条件的标签会被一起选中。

  • 点击列表中的标签，只播放该场景。
  • 用列表上方的排序（按时间线、按标签、按名称）,可以集中查看同类标签。

7. 整理成播放列表

播放列表用于收集并排列想给球员看的场景。打开播放列表后，视频下方会出现标签板。

  1. 用 新建播放列表 创建播放列表。
  2. 用标签列表的 ➕（或选中标签的 添加到播放列表）添加场景。也可以打开其他比赛的资料包，添加到同一个播放列表。
  3. 在标签板上拖动色带来排序或移到其他行。用 ➕ 添加行 可以增加行。
  4. 用行上的 ▶ 可按顺序连续播放该行。用 插入幻灯片 可以在场景之间插入说明页。
播放列表引用原资料包。移动或删除资料包后，相关场景将无法播放，请注意。交给别人时，用 📦 生成独立播放列表 可以做成没有资料包也能打开的形式。

8. 绘制战术（专业版）

效果模式是专业版功能。
  1. 按下标签列表（或播放列表场景）的 ✏️,进入该场景的效果模式。
  2. 从左侧工具中选择圆盘、聚光灯、箭头、区域等，在视频上绘制。圆盘和聚光灯只需点击球员就会自动跟随。
  3. 在下方时间线上调整绘制内容的显示时间。还可以加入“定格”，在想讲解的瞬间让视频停住。
  4. 绘制内容会自动保存。用 退出效果模式 回到原来的画面。

9. 导出为视频

  • 只导出一个场景：标签的 🎬 导出此片段
  • 把整个播放列表合成一个：🎬 导出为视频 在标签板上勾选行后，只导出这些行。
  • 每个场景分别导出文件：🗂 逐个导出片段

10. 从已剪好的片段开始

如果已有按场景剪好的视频文件，可以跳过打标签的步骤。

  1. 按下 从视频创建播放列表,一起选中视频文件。
  2. 每个文件成为一个场景，播放列表就完成了。
  3. 之后可以按照第 7~9 节同样地排序、绘制和导出。
