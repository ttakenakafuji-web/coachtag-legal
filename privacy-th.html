นโยบายความเป็นส่วนตัวของ CoachTag

ปรับปรุงล่าสุด: 23 ตุลาคม 2026

ภาพรวม

CoachTag ("แอป") เป็นแอป Mac, iPad และ Windows สำหรับวิเคราะห์วิดีโอฟุตบอล ติดแท็ก และวาดแท็กติก แอปจะไม่ส่งหรือจัดเก็บวิดีโอหรือข้อมูลการวิเคราะห์ของคุณไว้บนเซิร์ฟเวอร์ภายนอก ข้อมูลทั้งหมดอยู่บนอุปกรณ์ของคุณ (และในตำแหน่งที่คุณเลือกเอง เช่น iCloud Drive)

ข้อมูลที่เราเก็บรวบรวม

แอปไม่เก็บรวบรวมหรือส่งข้อมูลส่วนบุคคลใดๆ ไปยังเซิร์ฟเวอร์ของตนเอง โดยเฉพาะ:

  • ข้อมูลการวิเคราะห์ เช่น วิดีโอ แท็ก และภาพวาด: บันทึกเป็นไฟล์บนอุปกรณ์ของคุณเท่านั้น และจะไม่ถูกส่งออกนอกแอป (ไปยังเซิร์ฟเวอร์หรือที่อื่น)
  • การติดตามอัตโนมัติ (AI): การตรวจจับและติดตามผู้เล่นทำงานบนอุปกรณ์ของคุณทั้งหมดด้วยโมเดลที่มาพร้อมแอป วิดีโอจะไม่ถูกส่งไปที่ใด
  • ข้อมูลการสมัครสมาชิก (การซื้อ): การซื้อ การกู้คืน และการตรวจสอบวันหมดอายุดำเนินการบนอุปกรณ์ของคุณผ่าน App Store ของ Apple แอปไม่ส่งใบเสร็จไปยัง Apple หรือบุคคลที่สามด้วยตนเอง การชำระเงินดำเนินการโดย Apple และนโยบายความเป็นส่วนตัวของ Apple มีผลกับข้อมูลที่ Apple จัดการ บน Windows การซื้อและการตรวจสอบสถานะการสมัครสมาชิกจะดำเนินการผ่าน Microsoft Store และนโยบายความเป็นส่วนตัวของ Microsoft จะมีผลกับข้อมูลที่ Microsoft จัดการ
  • การวิเคราะห์การใช้งาน โฆษณา และการติดตาม: แอปไม่มี SDK สำหรับการวิเคราะห์ โฆษณา หรือการติดตามใดๆ

รายงานข้อขัดข้อง

หากแอปปิดลงโดยไม่คาดคิด macOS หรือ iPadOS อาจสร้างรายงานการวินิจฉัย ซึ่งเป็นฟีเจอร์มาตรฐานของระบบปฏิบัติการ รายงานจะถูกแชร์กับ Apple และผู้พัฒนาเฉพาะเมื่อคุณเปิดการแชร์ข้อมูลวิเคราะห์กับ Apple และผู้พัฒนาแอปไว้เท่านั้น แอปเองไม่เก็บรวบรวมหรือส่งข้อมูลนี้

บน Windows ระบบ Windows อาจเก็บข้อมูลการวินิจฉัยตามการตั้งค่าความเป็นส่วนตัวของคุณ แอปเองไม่ได้เก็บหรือส่งข้อมูลนี้

การแบ่งปันกับบุคคลที่สาม

เนื่องจากแอปไม่ส่งข้อมูลใดๆ ออกนอกอุปกรณ์ของคุณ จึงไม่มีการให้หรือแบ่งปันข้อมูลกับบุคคลที่สาม

การจัดการหรือยกเลิกการสมัครสมาชิก

คุณจัดการหรือยกเลิกการสมัครสมาชิกได้ทุกเมื่อที่ การตั้งค่า > Apple ID > การสมัครสมาชิก บน iPad หรือ การตั้งค่าระบบ > Apple ID > สื่อและการซื้อ > การสมัครสมาชิก บน Mac

บน Windows คุณจัดการหรือยกเลิกได้ทุกเมื่อที่ account.microsoft.com/services (บริการและการสมัครใช้งานในบัญชี Microsoft)
